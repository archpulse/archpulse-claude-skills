## ⚡ Швидкий старт

### Встановлення

1.  **Склонуйте або завантажте** цей репозиторій.
2.  **Встановіть усі навички** у свій робочий простір:

```bash
mkdir -p ~/.claude/skills
cp -r skills/* ~/.claude/skills/
```

3.  **Перезавантажте навички** у вашій інтерактивній сесії Claude:

```bash
/skills reload
```

## 🏆 Елітна Дев'ятка

Ці навички агресивно використовують **CodePulse**, **AST-аналіз** та **Історію Git** для вирішення ключових проблем ШІ при написанні коду.

| Навичка | Ключова концепція | Вирішена проблема |
|-------|----------------|------------------|
| **🛡️ [Zero-Trust Verifier](../docs/ZERO_TRUST.md)** | Обов'язкова перевірка декількома двигунами | Твердження "готово", які ламають білд |
| **🔮 [Blast Radius Oracle](../docs/BLAST_RADIUS.md)** | Аналіз транзитивних залежностей | Приховані регресії у спільному коді |
| **🏰 [Architectural Sentinel](../docs/ARCHITECTURE.md)** | Динамічний контроль архітектурних меж | Галюциновані імпорти та архітектурний дрейф |
| **🛑 [Anti-Loop Supervisor](../docs/ANTI_LOOP.md)** | Переривання циклів на основі відстані Левенштейна | Нескінченні повторювані невдалі виправлення |
| **🔪 [Context Slicer](../docs/CONTEXT_SLICER.md)** | Хірургічне вилучення AST-символів | Роздування контексту та шум у великих файлах |
| **🧪 [Regression Sentinel](../docs/REGRESSION.md)** | Автономні TDD скрипти відтворення | Виправлення, що не підтверджені об'єктивно |
| **🔗 [Temporal Mapper](../docs/TEMPORAL_COUPLING.md)** | Логічний зв'язок на основі Git | Забуті пов'язані конфіги/схеми |
| **🎯 [Semantic Test Selector](../docs/TEST_SELECTOR.md)** | Таргетоване тестування на основі графа | Ігнорування тестів через повільні набори |
| **🏗️ [Shadow Patch Simulator](../docs/SHADOW_PATCH.md)** | Ізольована перевірка правок у VFS | Багатофайлові виправлення, що ламають репозиторій |

## 🔍 Основна філософія

Традиційне написання коду за допомогою ШІ часто страждає від **"Передчасного святкування"** та **"Сліпоти локального контексту"**.

Цей набір навичок трансформує робочий процес:
1.  **Дослідження:** Використовуйте **Oracle** та **Mapper**, щоб побачити невидимі каскадні ефекти.
2.  **Планування:** Використовуйте **Simulator** для перевірки архітектурного впливу в пісочниці.
3.  **Виконання:** Використовуйте **Slicer** для високоточних правок з низьким рівнем шуму.
4.  **Верифікація:** Використовуйте **Verifier** та **Test Selector**, щоб гарантувати 100% надійність до того, як Claude скаже "Готово".
