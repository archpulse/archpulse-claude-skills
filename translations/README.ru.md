### ⚡ Быстрый старт

### Установка

1.  **Склонируйте или скачайте** этот репозиторий.
2.  **Установите все навыки** в рабочее пространство:

```bash
for s in *.skill; do claude skills install "$s" --scope workspace; done
```

3.  **Перезагрузите навыки** в интерактивной сессии Claude:

```bash
/skills reload
```

## 🏆 Элитная Девятка

Эти навыки агрессивно используют **CodePulse**, **AST-анализ** и **Историю Git** для решения ключевых проблем ИИ при написании кода.

| Навык | Главная Идея | Решаемая Проблема |
|-------|----------------|------------------|
| **🛡️ Zero-Trust Verifier** | Обязательная проверка несколькими инструментами | Утверждения "готово", которые ломают билд |
| **🔮 Blast Radius Oracle** | Анализ транзитивных зависимостей | Скрытые регрессии в общем коде |
| **🏰 Architectural Sentinel** | Динамический контроль границ слоев | Галлюцинации импортов и архитектурный дрейф |
| **🛑 Anti-Loop Supervisor** | Прерывание циклов на основе расстояния Левенштейна | Бесконечные повторные попытки неверных исправлений |
| **🔪 Context Slicer** | Хирургическое извлечение AST-символов | Раздувание контекста и шум в больших файлах |
| **🧪 Regression Sentinel** | Автономные TDD скрипты воспроизведения | Исправления, не подтвержденные объективно |
| **🔗 Temporal Mapper** | Логическая связь на основе Git | Забытые связанные конфиги/схемы |
| **🎯 Semantic Test Selector** | Таргетированное тестирование на основе графа | Игнорирование тестов из-за медленных наборов |
| **🏗️ Shadow Patch Simulator** | Проверка правок в изолированной VFS | Сложные правки, ломающие репозиторий |
